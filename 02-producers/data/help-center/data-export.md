You can export a single project or the whole workspace. Exports include tasks, subtasks, comments, labels and assignees. Attachments are exported separately as a ZIP file.

To export one project as CSV, open the project menu and choose Export, then CSV. Any member of the project can do this on every plan. The CSV has one row per task and subtask, with comments in a single column.

To export the whole workspace, an Owner or Admin opens Settings, then Data, then Export workspace, and chooses JSON. The JSON export keeps project structure, task dependencies and history, so it is the format to use for a migration or a backup. Workspace export is available on the Team and Business plans.

Fernway prepares the export in the background and emails a download link when it is ready, usually within an hour for large workspaces. The link is valid for 24 hours and can be used only by the person who requested the export.
